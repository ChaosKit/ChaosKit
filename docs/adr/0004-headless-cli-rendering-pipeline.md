# Headless CLI Rendering via Shared Offscreen OpenGL and Per-Thread Gathering

The headless CLI renderer (`cli/`, `chaoskit-render`) reuses the Qt UI's storage lowering (`ui_storage`), coordinate-to-pixel gathering (`ui::GathererTask`), and OpenGL 3.2 Core **Tone Mapping** shader (`ui::GLToneMapper`) via an offscreen OpenGL context (`QOffscreenSurface` and `QOpenGLFramebufferObject`), rather than maintaining a separate CPU tone mapper in `core/` or driving a full Qt Quick `SystemView` scene graph. To maximize throughput without `ui::HistogramGenerator`'s per-step Qt event-loop and mutex overhead, the CLI steps **Particles** in tight worker loops across hardware threads—each accumulating into a thread-local `GathererTask` **Histogram** buffer merged by summation before **Tone Mapping**—and automatically switches to single-threaded execution with a deterministic `pcg32` RNG whenever `--seed` is supplied.
