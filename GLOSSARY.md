# ChaosKit

ChaosKit is a tool and library suite for authoring and rendering fractal images generated by iterated function systems (IFS), inspired by and extending Fractal Flames.

## Language

### System & Authoring

**Project**:
The top-level authored unit containing a system along with its rendering configuration (image dimensions, color map, and tone mapping settings).
_Avoid_: Document

**System**:
An iterated function system consisting of weighted blends, an optional camera, and a particle lifetime range.

**Blend**:
A single weighted branch of a system, combining a pre-affine transform, a weighted sum of formulas, a post-affine transform, and a coloring method.
_Avoid_: Transform, Xform

**Isolated Blend**:
A single blend temporarily soloed so that the system executes it exclusively instead of choosing randomly among enabled blends.

**Camera**:
An optional, non-feedback blend applied to each particle's state solely for plotting, without altering the particle's trajectory in subsequent iterations.
_Avoid_: Final Blend, Final Transform

**Affine Transform**:
A 2D linear transformation and translation matrix applied before or after a blend's formulas.
_Avoid_: Matrix

**Formula**:
A parameterized non-linear 2D mathematical function combined by scalar weight within a blend.
_Avoid_: Variation

### Simulation & Rendering

**Particle**:
A point in 2D space carrying a color coordinate and remaining iteration counters as it is stepped through a system.

**Lifetime**:
The range of iterations (`[Min, Max]`, or `Infinite`) during which a particle is plotted before being re-randomized, with iterations prior to `Min` executed as unplotted warm-up steps.
_Avoid_: TTL, Skip

**Color Coordinate**:
The scalar value in $[0, 1]$ carried by a particle and transformed on each iteration before being mapped to an RGBA color.
_Avoid_: Color Index, Color

**Coloring Method**:
A rule on a blend or camera that computes a particle's new color coordinate from its spatial trajectory, current color coordinate, and a scalar parameter.

**Color Map**:
A lookup function on a project that converts a particle's scalar color coordinate in $[0, 1]$ into an RGBA color when plotting to the histogram.
_Avoid_: Palette, Gradient

**Histogram**:
A 2D accumulation grid of RGBA color sums and hit counts produced by plotting particles over time.

**Tone Mapping**:
The post-processing stage that converts accumulated histogram densities and colors into a displayable image using logarithmic scaling, exposure, gamma, and vibrancy.
